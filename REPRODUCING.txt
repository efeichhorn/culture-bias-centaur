SETUP

Use Python 3.10–3.12 for CPU work. Run commands from this repository root.

python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt

provenance/cpu_environment.txt records the tested CPU package versions.
requirements-training.txt is only needed for GPU training or inference.

FULL CPU REANALYSIS

make data
make analysis

The archive is about 47 MB and expands to 2.81 GB. Extraction checks every
file's SHA-256 hash. See data/README.md for schemas and original source links.

scripts/reproduce_analyses.py reruns the frozen-model comparisons, 126-fit
analysis, response adjustments, balanced Taking analysis, participant
bootstraps, and Figure 2 data export. It compares the regenerated tables with
results/ and writes build/reanalysis/verification.json. New outputs stay in
build/reanalysis/. The reference tables in results/ are not replaced.

Each bootstrap uses 4,000 resamples and the recorded seed. Numerical checks
allow 1e-10 rounding differences between CPU libraries. Training fits and
items are fixed; the intervals do not cover new training samples or items.

To store extracted data elsewhere:
python scripts/prepare_paper_data.py --output /path/to/workspace
make analysis WORKSPACE=/path/to/workspace

GPU RUNS

These commands run from the repository root, after extracting data/paper_inputs.zip.
They use the original prepared responses and participant splits. New model fits
go to build/retrain; the saved paper results stay in data/workspace.

The recorded environment used Python 3.12.13, Torch 2.10.0+git8514f05,
Transformers 5.5.4, Accelerate 1.13.0, PEFT 0.19.1, bitsandbytes 0.50.2,
and safetensors 0.7.0. See provenance/giving_taking_runtime.json and
provenance/cao_anllo_runtime.json. Install a working ROCm/CUDA PyTorch build
before requirements-training.txt. The original custom Torch build is not
provided. Install GPU PyTorch for your system using https://pytorch.org/get-started/locally/,
then run: python -m pip install -r requirements-training.txt
The code checks GPU availability, adapter APIs and zero-step model
equivalence before training; the target GPU environment still needs a smoke run.

Model IDs:
  unsloth/Meta-Llama-3.1-70B-bnb-4bit
  marcelbinz/Llama-3.1-Centaur-70B-adapter

The historical records do not record Hugging Face commit revisions. Model IDs
and runtime versions are known; exact upstream model revisions are not verified.

BINARY TASKS: TWO SMOKES, TWO FROZEN REFERENCES AND 81 FITS

These manifests contain the original fixed item folds and training targets.
The binary trainer evaluates frozen and trained models in the same process.
No separate evaluate command is needed after a successful train command.

export WORKSPACE TRAIN_OUTPUT
python - <<'PY'
import json
import os
from pathlib import Path
import subprocess
import sys

source = Path(os.environ["WORKSPACE"]) / "publication-bias-transfer-demo"
output_root = Path(os.environ["TRAIN_OUTPUT"]) / "binary"
index = json.loads((source / "data_cache/culture_extensions_20261021/runs/run_index.json").read_text())

def run(entry, stage):
    dataset = entry["dataset"]
    manifest = source / entry["manifest"]
    if stage == "train":
        output = output_root / dataset / f"seed{entry['seed']}" / f"fold{entry['fold']}" / entry["condition"]
    else:
        output = output_root / ("baseline_precision_aligned" if stage == "baseline" else "smoke") / dataset
    subprocess.run([
        sys.executable, "scripts/culture_extension_centaur70b.py", "--stage", stage,
        "--run-manifest", str(manifest), "--output-dir", str(output),
        "--micro-batch-size", "24" if dataset == "cao" else "12",
    ], check=True)
    subprocess.run([
        sys.executable, "scripts/validate_culture_extension_run.py", "--stage", stage,
        "--run-manifest", str(manifest), "--output-dir", str(output),
    ], check=True)

for dataset in ("cao", "anllo"):
    first = next(entry for entry in index["runs"] if entry["dataset"] == dataset
                 and entry["seed"] == 0 and entry["fold"] == 0 and entry["condition"] == "us")
    run(first, "smoke")
    run(first, "baseline")
for entry in index["runs"]:
    run(entry, "train")
PY

CLUSTER RUNNERS

slurm/run_dictator_centaur70b_corrected.sh and
slurm/run_culture_extension_20261021.sh provide the original cluster setup.
Set HF_HOME, VIPER_PYTHON_OVERLAY and VIPER_TRAIN_CONTAINER, then choose the
account, partition, memory and GPU allocation for your cluster. Both runners
validate outputs before marking a job complete. The portable commands above
can run without Slurm or the original container.

sources. SHA256SUMS lists its files; a separate .zip.sha256 checks the ZIP.
