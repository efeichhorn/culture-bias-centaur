\section{Methods}
\label{sec:methods}

\subsection{Tasks}
\begin{itemize}
\item \textbf{Giving / Taking} \citep{wang2026decomposing}: give tokens to, or take tokens from, members of different social groups. Fine-tune on Giving only; evaluate Giving and Taking. More giving and less taking mean greater generosity.
\item \textbf{Categorization} \citep{cao2024differences}: category-based versus relation-based word choices. Fine-tune on some items; evaluate unseen items.
\item \textbf{Lotteries} \citep{anllo2024preferences}: choices between explicit lotteries. Fine-tune on both tradeoff and dominance items; report their held-out results separately.
\end{itemize}

\subsection{Comparison}
\begin{itemize}
\item Start from the same frozen Centaur model. Add an adapter fine-tuned on US, Chinese, or 50/50 pooled responses.
\item Equal data budgets and optimization settings within each task; three split/fitting seeds.
\item Participants per adapter: 910 for Giving, 124 for categorization, 34 for lotteries. Pooled uses half from each country at the same total budget.
\item Hold out complete participants and items. Keep repeated responses together. Taking never enters fine-tuning or model selection.
\item Identical English prompts without country labels. Average both answer orders for binary choices.
\item Include frozen Centaur and base Llama as references. Llama receives no additional fine-tuning.
\end{itemize}

\subsection{How each hypothesis is tested}
\begin{itemize}
\item \textbf{H1:} Compare frozen prediction error across populations. Report the US--China error difference and, separately, the difference in improvement over Llama.
\item \textbf{H2:} Compare US-adapter minus China-adapter expected responses on the same unseen items. Show pooled fine-tuning alongside both.
\item \textbf{H3:} Compare that adapter contrast on Taking with the human US--China contrast, including its direction and size. Check predictive accuracy separately.
\item \textbf{H4:} Report adjustment NLL minus fine-tuned NLL on the same test responses. Positive values favor fine-tuning.
\item Measures: expected tokens or choice probability for shifts; conditional negative log likelihood for fit (lower is better).
\end{itemize}

\subsection{Response adjustment}
\begin{itemize}
\item Reweight frozen probabilities by one response preference shared across items:
\[
q_{\delta}(y\mid x)=\frac{p_0(y\mid x)e^{\delta_y}}{\sum_k p_0(k\mid x)e^{\delta_k}}.
\]
\item Allocation: 21 token responses, with offsets constrained to sum to zero (20 free parameters). Fit on the adapter's Giving participants and targets; reuse the same offsets for Giving and Taking.
\item Binary choices: one offset to the semantic log odds, fitted before averaging the two answer orders. Positive means category choice or the 10-point lottery option. Keep the saved ridge penalty fixed; give its exact form in the appendix.
\item This control can learn a general response preference without changing model weights. It cannot independently correct answer-position bias; a gain over it alone does not establish richer cultural learning.
\end{itemize}

\begin{itemize}
\item Uncertainty: resample whole participants, retaining dependence across overlapping splits. Show seed variation separately; folds and repeated trials are not independent samples.
\item Allocation intervals are available. Paired uncertainty for categorization and lotteries remains to be completed.
\end{itemize}
