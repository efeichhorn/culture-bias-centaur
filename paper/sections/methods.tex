
\section{Methods}
\label{sec:methods}

\subsection{Tasks}
\begin{itemize}
\item \textbf{Giving / Taking} \citep{wang2026decomposing}: tokens given to, or taken from, members of different social groups. Fine-tuning on Giving only; evaluation on Giving and Taking. More giving and less taking mean greater generosity.
\item \textbf{Categorization} \citep{cao2024differences}: category-based versus relation-based word choices. Fine-tuning on a subset of items; evaluation on unseen items.
\item \textbf{Lotteries} \citep{anllo2024preferences}: choices between explicit lotteries. Fine-tuning on both tradeoff and dominance items; separate held-out results for each type.
\end{itemize}

\subsection{Comparison}
\begin{itemize}
\item Same frozen Centaur model, with separate adapters fine-tuned on US, Chinese, or 50/50 pooled responses.
\item Equal data budgets and optimization settings within each task; three split/fitting seeds.
\item Participants per adapter: 910 for Giving, 124 for categorization, 34 for lotteries. Pooled uses half from each country at the same total budget.
\item Complete participants and items held out from fine-tuning; repeated responses stay in the same split. Taking never enters fine-tuning or model selection.
\item Identical English prompts without country labels. Binary-choice predictions averaged across both answer orders.
\item Reference models: frozen Centaur and base Llama. Llama receives no additional fine-tuning.
\end{itemize}

\subsection{How each hypothesis is tested}
\begin{itemize}
\item \textbf{H1:} Frozen prediction error by population: the US--China error difference and, separately, the difference in improvement over Llama.
\item \textbf{H2:} US-adapter minus China-adapter expected responses on the same unseen items, with pooled fine-tuning alongside both.
\item \textbf{H3:} Adapter contrast on Taking alongside the human US--China contrast: direction and size. Predictive accuracy is a separate outcome.
\item \textbf{H4:} Adjustment NLL minus fine-tuned NLL on the same test responses. Positive values favor fine-tuning.
\item Measures: expected tokens or choice probability for shifts; conditional negative log likelihood for fit (lower is better).
\end{itemize}

\subsection{Response adjustment}
\begin{itemize}
\item Frozen probabilities reweighted by one response preference shared across items:
\[
q_{\delta}(y\mid x)=\frac{p_0(y\mid x)e^{\delta_y}}{\sum_k p_0(k\mid x)e^{\delta_k}}.
\]
\item Allocation: 21 token responses, with offsets constrained to sum to zero (20 free parameters). Offsets fitted on the adapter's Giving participants and targets, then applied to both Giving and Taking.
\item Binary choices: one offset to the semantic log odds, fitted before averaging the two answer orders. Positive means category choice or the 10-point lottery option. Fixed ridge penalty; appendix specification pending.
\item This control can learn a general response preference without changing model weights. It cannot independently correct answer-position bias; a gain over it alone does not establish richer cultural learning.
\end{itemize}

\begin{itemize}
\item Uncertainty plan: whole-participant resampling, retaining dependence across overlapping splits. Seed variation shown separately; folds and repeated trials are not independent samples.
\item Allocation intervals are available. Paired uncertainty for categorization and lotteries remains to be completed.
\end{itemize}
