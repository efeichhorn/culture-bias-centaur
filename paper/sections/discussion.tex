\section{Discussion and Limitations}
\label{sec:discussion}

\begin{itemize}
\item Main interpretation: fine-tuning population changes what Centaur predicts. This can reflect a learned response tendency without better prediction or faithful transfer.
\item Response adjustment tests what changing model weights adds beyond changing a general response preference.
\item Population-specific shifts can persist without improving on frozen Centaur in every condition or reproducing human differences after transfer. H2 establishes sensitivity; H3 and H4 test what that sensitivity achieves.
\item No consistent Western prediction advantage; the population ordering changes across tasks.
\end{itemize}

\subsection{Limits}
\begin{itemize}
\item Country, language, recruitment, and other sample differences remain intertwined; nationality is not a direct measure of culture.
\item Few items, small lottery test samples, and only three seeds. Repetitions do not add independent people.
\item Lower prediction error can partly reflect more predictable human responses.
\item Frozen Llama comparisons do not show whether Centaur's original fine-tuning causes the observed sensitivity.
\item Exploratory dataset selection and uncertain prior model exposure limit generalization.
\item Giving-to-Taking is one transfer test. A wave-dependent human contrast cannot support a universal failure-of-transfer claim.
\end{itemize}
