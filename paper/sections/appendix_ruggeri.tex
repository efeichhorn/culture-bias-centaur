\section{Supporting Audit: Temporal Discounting}
\label{app:ruggeri}
\begin{itemize}
\item Released frozen predictions for \citet{ruggeri2022globalizability}; no additional fine-tuning.
\item Country metadata verified for most test participants, covering all 61 countries. Some participant metadata remain missing.
\item Main comparison weights countries equally; the Western grouping is an operational geographic definition.
\item No clear Western prediction advantage. This does not establish equivalence between groups.
\item Seen-study evaluation: Ruggeri was represented in Centaur's original fine-tuning corpus.
\item Scores use full-vocabulary likelihood and earlier observed answers. Do not pool them numerically with the main independent-choice results.
\end{itemize}
